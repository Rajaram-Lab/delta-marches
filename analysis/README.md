# Analysis Results

This directory serves as a placeholder for inference results and intermediate analysis artifacts used by the Delta-Marches workflows and plotting notebooks. Populate it with the outputs generated by the relevant analysis scripts and any required evaluation annotations.

Typical contents include:

- Extracted latent representations (`train_patients_AAE_lat_vector_*.pkl` and `test_patients_AAE_lat_vector_*.pkl`).
- Segmentation outputs, image-classifier predictions, and model explanations (`.pkl` and `.npy` files).
- Ground-truth annotations and pathologist assessments (`gt_all.xlsx` and `ans*_all.xlsx`).

See the [analysis guide](../code/README_analysis.md) for the workflows and the [plotting guide](../code/plotting_notebook/README.md) for visualization instructions.

## Using Another Storage Location

Results and annotations may be stored in another directory. Update the corresponding paths in [data/data_dir.yaml](../data/data_dir.yaml), including `latent_space`, `HoverNet_mask`, `ViT_grade_pred`, `ViT_explanation`, and `pathologist_result`, to point to your files. Preserve the expected file formats and data structures.

Use absolute paths for external storage, or paths relative to the repository root when running scripts and notebooks from that directory. Update any script-specific paths separately if they are not loaded from the YAML configuration.
